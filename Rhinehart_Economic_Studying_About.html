About This Project

This project was founded and developed by me, Wesley Rhinehart. The tools used to code each module are as follows:

  • Python: Used to build the interactive study modules, generate questions, validate answers, calculate scores, and provide personalized feedback throughout each module.
  • Visual Studio Code: Used as the main development platform to write, organize, test, and debug the project's Python code.
  • GitHub Copilot: Used as an AI coding assistant to help write, troubleshoot, refine, and improve the Python code. GitHub Copilot was used strictly as a tool for Python refinement. This refinement includes original code written by me, including both functionality and aesthetics. All visual effects and HUDs were animated by GitHub Copilot, while all original ideas came from me. All data and questions entered into the Rhinehart Economic Studying database were hand-crafted from course notes and independent research.
  • GitHub: Used to store, manage, and track the project's source code, keeping version control organized throughout development.

All code for each individual module can be found and downloaded for free on my GitHub profile, listed on the Social Page.
